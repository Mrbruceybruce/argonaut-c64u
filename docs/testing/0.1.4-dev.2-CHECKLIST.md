# Argonaut 0.1.4-dev.2 testing checklist
Windows, Apple Silicon, and Intel Mac

Historical checklist: the 0.1.4-dev.2 test Release and its attached downloads
were intentionally removed during repository cleanup. The Git tag remains,
but does not restore those packages or checklists. For stable downloads, use
the [Releases page](https://github.com/Mrbruceybruce/argonaut-c64u/releases);
for current build guidance, see [RELEASING.md](../RELEASING.md).

Use a separate copy for each platform.

- [ ] **1. Discovery:** Open Preferences > Connections. Try Scan again and Scan subnet on your LAN. Confirm the C64U appears, select it, test the connection, and connect.

- [ ] **2. Device details:** Enter Serial number and Box model (the model checked on the shipping box) for each profile. Save profile details, reopen, and confirm each profile retains its own values.

- [ ] **3. Reported model:** Click Read model from C64U. Confirm the correct model appears and cannot be edited.

- [ ] **4. Checkboxes:** In General, clicking far to the right of a checkbox label should do nothing. Clicking its box or label should toggle it.

- [ ] **5. Default scale:** Set 175% in General and save. Quit and reopen Argonaut; the preview should use 175%.

- [ ] **6. Temporary scale:** On Streams, use minus/plus from 100% to 300%, in 25% steps. The value must be read-only and stay within these limits. Restart; it should return to 175%.

- [ ] **7. Preview overflow:** Increase scale until the preview exceeds the viewing area. Scrollbars should appear, the preview should remain reachable, and the application window should stay the same size.

- [ ] **8. Text input:** Confirm Append Return starts checked. At BASIC READY, send PRINT "HELLO" and confirm it executes.

- [ ] **9. Quick regression:** Check file copy, a screenshot, a short recording with audio, and Mount & Run with a test D64. Mount & Run requires the C64U DMA network service.

- [ ] **10. Quit:** Test normal window closing and reopening. On Mac, also test Cmd-Q and menu Quit.

Windows portable: Copy the previous Data folder into the newly extracted folder to retain development profiles.

Report failures on GitHub Issues at https://github.com/Mrbruceybruce/argonaut-c64u/issues with the platform, About build, checklist item, and observed result.
