# Debian development pass 3

> Historical 0.1.4 development notes; the corresponding test Release was removed.
> See [release guidance](../RELEASING.md) for the current build process.

General, Device details, and About now share Preferences. Device details combines connection controls and editable shipping-box details in one scrollable page. The firmware-reported model remains read-only and can differ from the shipping-box model.

Close and the window close control offer Save, Discard, or Keep editing when General or the current profile has unsaved edits. Save preferences keeps the dialog open. Connecting saves the selected profile and reports success without closing Preferences.

Preview scale uses a percentage label with minus/plus buttons. Enter in the Streams text field sends text, using the same connection and busy checks as Send text.

Discovery repeats its bounded Ident broadcast and verifies saved profile addresses. Generic authentication responses alone no longer appear as C64Us; password-protected Ident advertisements remain unverified until connected. Mac reliability needs a later Mac package test.

Package metadata retains the package version in About. Source fingerprints normalize text line endings. Build automation can supply ARGONAUT_SOURCE_COMMIT with the full reviewed commit ID when Git is unavailable. A source fingerprint and a Git commit ID are different forms of identity; compare each with the matching package record.

Instance review: GTK presents the existing application when desktop application registration supports it (confirmed on GNOME). Windows does not reliably provide the same registration service. No Windows instance-locking change is included in this Debian pass. Multiple clients can send operations to the same C64U, so this remains a Windows follow-up.

The Debian development package uses a separate package name, launcher, and settings directory. Stable Argonaut remains separate. Future testing checklists are interactive PDF forms.
