# Argonaut application icon

Artwork supplied by Bruce Marcus for Argonaut. The original PNG is preserved in
`argonaut-source.png`. Native icon formats and PNG sizes are derived from that
image without changing the design. Distributed under the project’s GPL-3.0-or-later license.

- Windows EXE and installer: `argonaut.ico`
- macOS app bundle: `argonaut.icns`
- Linux desktop launcher: `argonaut-SIZE.png` in the hicolor icon theme
