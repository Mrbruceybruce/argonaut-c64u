Experimental **Intel (x86_64) Mac package, macOS 15 or newer**.

Download the DMG, open it, and drag Argonaut into Applications. Python and Homebrew are not required. The ZIP contains the same app.

Automated unit tests, packaged startup/About/media-plugin checks, relocation and signature verification passed on GitHub's Intel Mac runner. **Physical Intel Mac testing is still needed.** This prerelease does not replace the stable 0.1.4 downloads.

The app is ad-hoc signed, not Apple-notarized. If macOS blocks it, use the per-app Open Anyway option in Privacy & Security for this trusted download.

Please report your Mac model, macOS version, and About build identifier. Test launch, C64U connection, a disposable file upload/download, preview video/audio, and saved profiles after restart. Preview requires Ethernet on the C64U and incoming UDP 11000–11001 on the Mac.
